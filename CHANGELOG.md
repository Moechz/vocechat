# Changelog

All notable user-visible changes to the VoceChat TOS application package.

## 0.5.17-1 — 2026-11-12

### Added
- First release. VoceChat (`privoce/vocechat-server:v0.5.17`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8110 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/vocechatdocker/`.
